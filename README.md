# 心海海 · 桌宠 🌊

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](../LICENSE)

一只有情绪、要吃喝、有作息、会打工赚钱、会满屏溜达的 Windows 桌面宠物。形象为 Q 版矢量卡通(青绿长发 + 红瞳 + 红蝴蝶结,和风巫女短衫红裙),灵感致敬《千恋＊万花》丛雨。

> 说明:原游戏立绘为 Yuzusoft 版权素材,本程序**未使用任何官方图片**,而是用矢量图重新绘制。想 100% 还原,见「换成自己的立绘」。

## 一键运行

解压完整包后目录应是：

```
Table_pet_xinhaihai_v1.6.0\
  心海海.exe     ← 启动器,双击运行（自包含,无需装 .NET）
  README.md
  skin\          ← PNG 自定义皮肤
  live2d\        ← Live2D 模型
  gif\           ← GIF 动画皮肤
  XinHaiHai\     ← 源码(可选,不删不影响运行)
```

`心海海.exe` 必须和 `skin` / `live2d` / `gif` **同一层**。双击即可,她会从屏幕右下角登场。

- 托盘有「心海海」图标:双击隐藏/唤出,右键退出。随时可退,随时可关。
- 数据目录:`%APPDATA%\心海海\`(配置、状态、日志、任务库、每日计划)。

## 任务库(tasks.txt)

首次运行自动生成 `%APPDATA%\心海海\tasks.txt`(16 种休闲 + 8 种工作)。格式:

```
# 休闲:名称,最短分钟,最长分钟              (15~90 分钟)
练习剑术,45,90
# 工作:名称,最短分钟,最长分钟,工作,强度      (强度 1~5,越高工资越高)
除灵委托,60,90,工作,5
```

工资在**完成时**按【强度 × 时长】随机结算 **75~200 金币**,不用自己填。随便加删改,改完保存 → 右键「重新规划今天」立即生效。也可把 tasks.txt 放 exe 同目录(优先级更高)。

## 金币经济

- **赚钱**:每天至少 1 件工作任务,完成按强度×时长随机发 75~200 金币,自动到账(错过启动也补发)。一天下来轻松几百金币。
- **花钱**:
  - 投喂(便宜,维持温饱):清水 8、梅子饭团 18、握寿司 55、妖怪火锅 120……
  - 礼物(贵,买开心):水果糖 60、祭典灯笼 560(加护1h)、夏夜烟花 1500(加护4h)、约定戒指 7500(加护3天)、落星之愿 12000(加护7天)。
- **加护**期间她视同时刻被陪伴:满快乐值、不听歌、不抢鼠标。

## 配置(config.json)

```jsonc
{
  "musicCommand": "",           // 指定播放器路径/网址;留空自动探测(网易云/QQ/酷狗/酷我/Spotify…)
  "musicAutoPlay": true,        // 打开播放器后自动按媒体键放歌
  "musicPlayDelaySeconds": 12,  // 播放器冷启动后等几秒再按播放
  "mischiefEnabled": true,      // 快乐见底是否允许抢鼠标
  "listenModeEnabled": true,    // 检测你在听歌就陪你一起听(快乐缓慢上升)
  "autoEatThreshold": 30,       // 饥饿/口渴低于此值且没人喂,她会自己买吃的
  "timeScale": 1.0,             // 调试:时间加速倍率

  // —— 对话模式(见下方「双对话模式」)——
  "dialogueMode": "local",      // local=本地 JSON 台词随机;llm=接大模型按人设即时生成
  "llmBaseUrl": "https://api.openai.com/v1",  // OpenAI 兼容接口地址(会自动拼 /chat/completions)
  "llmApiKey": "",              // API 密钥;留空则即便选了 llm 也回退本地台词
  "llmModel": "gpt-4o-mini",    // 模型名(如 gpt-4o-mini / deepseek-chat 等)
  "llmPersona": "…",            // 人设提示词(可自由改),{name} 代表桌宠名字
  "llmTimeoutSeconds": 6,       // 大模型响应超时秒数,超过就跳过本次台词
  "llmTemperature": 0.9         // 采样温度,越高越活泼多变
  // 其余 debug* 项见文件内注释,正常使用无需改动
}
```

提示:若播放器已在运行,她直接让它播,不重复启动;网页版兜底无法自动播放(浏览器限制)。听歌模式靠系统输出音量峰值判断,需要有已知播放器进程在发声。

## 双对话模式(右键 →「对话模式」随时切换)

桌宠说的话有两种来源,随时切换、互不影响:

### ① 本地台词(默认)
从 `data\lines_{形象}.json` 里**随机抽取**。零延迟、离线可用、可自由编辑;官方/自定义形象是丛雨风,Live2D 是初音风。

### ② 大模型对话(需配置)
接入 **OpenAI 兼容接口**,按**可修改的人设**即时生成台词,每次互动都不重样。

出厂默认(已重置为初始状态,不填密钥就不会走大模型):

| 项 | 默认值 |
|---|---|
| 对话模式 | `local`(本地台词) |
| 接口地址 | `https://api.openai.com/v1` |
| API 密钥 | 空 |
| 模型名 | `gpt-4o-mini` |
| 超时 | 6 秒 |
| 温度 | 0.9 |

**用 OpenAI 官方接口时要做这些:**

1. 打开 [https://platform.openai.com](https://platform.openai.com) 注册/登录,在 API keys 里新建一把密钥(`sk-…`)。账户需要有可用额度。
2. 右键桌宠 → **对话模式** → **大模型设置 / 人设…**
3. 按下面填:
   - **接口地址**:`https://api.openai.com/v1`(不要写成聊天网页,末尾到 `/v1` 即可,程序会自动拼 `/chat/completions`)
   - **API 密钥**:粘贴你的 `sk-…`
   - **模型名**:`gpt-4o-mini`(也可改成你账号能用的别的模型)
   - **人设**:可改,用 `{name}` 代表桌宠名字
4. 点 **测试连接**。成功后再切到「大模型对话」。
5. 密钥只存在本机 `%APPDATA%\心海海\config.json`,不上传别处。

**不想用官方 OpenAI 时:**任何 OpenAI 兼容服务都行(DeepSeek、本地 Ollama、中转站)。把 baseUrl 换成对方的 `/v1` 地址,密钥和模型名按服务商文档填。密钥留空时,即便选了大模型也会自动回退本地台词。

- 内置硬约束:**只输出简体中文、单句、去掉引号旁白**,句子过长自动截断;
- **6 秒超时保护**:大模型若 6 秒内没返回(或接口报错),**自动取消本次台词**——快乐值增加、动画、走动等其它功能全程照常,绝不卡住。

## 外观四模式(右键 →「外观切换」随时换)

### ① 官方形象
内置 Q 版矢量丛雨风形象,零配置,表情/眨眼/挥手动画齐全。

### ② 自定义皮肤(PNG)
exe 同目录建 `skin` 文件夹,放透明背景 PNG(约 220×272):

- `idle.png`(必需)+ `happy / bored / angry / sleep / music / busy / hungry.png`(可选,缺省回退 idle)
- 切到该模式即生效;想找目录:右键 → 外观切换 →「打开皮肤目录」

### ③ GIF 动画
exe 同目录建 `gif` 文件夹,放 GIF 动画:

- `idle.gif`(必需)+ `happy / bored / angry / sleep / music / busy / hungry.gif`(可选,缺省回退 idle)
- 右键 → 外观切换 →「GIF 动画模式」即可加载帧动画
- 默认会把纯黑/极暗背景抠成透明,透明区域鼠标穿透;可在配置里关 `blackToTransparent`

### ④ Live2D 模型(真·Cubism 2/4)
exe 同目录建 `live2d` 文件夹,三选一:

1. **放整个模型文件夹**(含 `xxx.model3.json`(Cubism4)或 `xxx.model.json`(Cubism2)、moc、贴图、动作),程序自动找到并加载;
2. 或建一个 `model_url.txt`,里面写一行模型 json 的**网址**(在线加载);
3. 进阶:把 `pixi.min.js`、`index.min.js`(pixi-live2d-display)、`live2dcubismcore.min.js`、`live2d.min.js` 放进 `live2d\libs\`,即可**完全离线**使用。

说明:
- 模型自带待机动作会自动播放,呼吸/眨眼由模型驱动;
- 渲染层做了鼠标穿透处理,拖拽、右键菜单一切照旧;
- 依赖 **WebView2 运行时**(Win10/11 一般自带);未放本地 libs 时**首次加载需联网**拉取渲染库(之后走缓存);
- 模型加载成功会弹泡「Live2D 形象,登场!」,失败会提示原因(看 `%APPDATA%\心海海\log.txt`)。
- 找模型:Live2D 官方示例模型、或你持有版权/授权的模型均可。**请遵守模型作者的使用条款。**

模式选择保存在配置里,重启不变;`skinMode: "auto"`(默认)= 有 PNG 皮肤就用皮肤,否则官方形象。缩放存在 `petScale`(0.5~3.0)。

## 改名字

## 我的世界(Minecraft)联机

桌宠可以进入 MC 服务器聊天、互动、执行指令,原版/Fabric/Forge/NeoForge 全版本通用,不装模组。

### 前置要求

- [Node.js](https://nodejs.org)(v18+)
- 在 `mc/` 目录下执行 `npm install`(首次安装 mineflayer 依赖)

### 怎么连接

右键桌宠 → **我的世界**:

| 选项 | 说明 |
|------|------|
| **连接本机(127.0.0.1)** | 你自己的电脑开了 MC 服,直接点这个 |
| **连接 Sakura FRP…** | 别人的服、或者用内网穿透,弹窗填服务器地址和端口,点连接 |

### 你的服怎么开

最简单:桌面上开 MC → 对局域网开放 → 记下端口号(比如 25565) → 桌宠点「连接本机」。

也可以用原版服务端、Forge 服务端、Fabric 服务端等。确保 `server.properties` 里 `online-mode=false`(离线服),桌宠才能连上。

### 自动拿 OP

桌宠进服后会自动发 `/op XinHaiHai`。如果没生效(有些服第一次需要手动),在游戏里打 `/op XinHaiHai` 即可。

### 游戏内聊天

- 游戏里别人说话 → 桌宠用大模型判断:
  - **聊天** → 用人设回话(气泡 + 游戏内发言)
  - **指令**(如「把我tp到xxx」) → 自动执行 `/tp XinHaiHai xxx`
  - 没配大模型 → 回本地台词,不执行指令
- 右键 → **我的世界** → **MC中说句话…** → 弹窗打字回车直接发到游戏

### Sakura FRP 穿透

服不在本机时:

1. 装了服务器的那台电脑上装 [Sakura FRP](https://www.natfrp.com),建一个 TCP 隧道,本地端口填 25565
2. 启动隧道,记下分配的域名(如 `xxxxxx.frcp.cn`)
3. 桌宠右键 → 我的世界 → 连接 Sakura FRP → 地址填域名,端口填 25565 → 连接

### 连接云服务器(最通用)

如果你的服在云服务器上(阿里云、腾讯云、自己的 VPS 等),Sakura FRP 用不了也没关系:

1. 右键桌宠 → 我的世界 → **连接云服务器**
2. 弹窗填入云服务器的 IP 地址(如 `123.45.67.89`)和端口(默认 25565)
3. 点连接,桌宠会自动连上

云服务器需要:
- 服务器端口已开放(防火墙/安全组放行 25565 或你用的端口)
- `server.properties` 里 `online-mode=false`(离线服)

这种方式最通用:只要你的云服务器能访问到,不管在国内还是国外,桌宠都能连。

### 支持的版本

原版 1.8~1.21+ / Fabric / Forge / NeoForge 全部通用。桌宠不装模组,只用登录协议连服。服务器需要 `online-mode=false`。
